# 判定ルーブリック

## 判定の意味

| 主判定 | 条件 |
|---|---|
| `supported` | 次のいずれかを満たす。(1) 射程移送がなく、原研究が命題を直接扱っている。(2) 射程移送があり、原研究が移送元の命題を直接扱い、検証済みの十分な橋渡し根拠が移送先への適用を支持している。いずれの場合も、根拠で説明されていない対象、操作、評価項目、文脈、確実性の差が結論を変えるものでない |
| `caveat_required` | 中核的な方向は原研究と整合するが、対象範囲、条件、効果の大きさ、不確実性、代替説明のいずれかを明示しないと誤解を招く |
| `unsupported` | 原研究が命題を検証していない、原研究と矛盾する、または結論に不可欠な推論の格上げや射程移送を支える根拠を確認できない |
| `検証不能` | 原論文の全文、重要な補足資料、資料の同一性のいずれかを確認できず、上の3判定を安全に付けられない |

`caveat_required` と `unsupported` の境界は、限定表現だけで原研究に沿うかで決める。限定語を補えば原研究が直接支える命題になる場合は `caveat_required` とする。新しい比較研究、因果識別、価値前提など、別の根拠が必要な場合は `unsupported` とする。

## 原研究との整合性

次の差が援用主張の結論を変えるかを確認する。

- 著者の結論より強い確実性を使っていないか。
- 主要評価項目と副次評価項目を入れ替えていないか。
- 統計的有意性を効果の大きさや実用上の重要性と同一視していないか。
- 相対効果だけを示し、絶対効果や基準率を隠していないか。
- 探索的解析や事後解析を事前仮説の検証として扱っていないか。
- 否定的結果を「効果がない証明」として扱っていないか。
- 除外基準、脱落、欠測、測定誤差、交絡、バイアスを落としていないか。

## 射程移送の軸

| 軸 | 典型的な飛躍 | 必要になり得る橋渡し根拠 |
|---|---|---|
| 種 | 動物や細胞から人間 | 機序の比較、薬物動態、臨床研究、トランスレーショナル研究 |
| 集団 | 限定標本から別集団 | 代表性、再現研究、効果修飾、外的妥当性の分析 |
| 集団から個人 | 平均差から個人の能力や性質 | 個人レベルの予測妥当性、誤分類率、基準率 |
| 文化・地域 | 一地域から普遍的傾向 | 測定不変性、文化間比較、制度差の分析 |
| 時代 | 過去の結果から現在 | 環境変化、コホート効果、再現研究 |
| 制度 | 実験環境から政策・組織運用 | 実装研究、制度比較、副作用、分配影響 |
| 概念 | 測定指標から広い概念 | 構成概念妥当性、収束的・弁別的妥当性 |

差があるだけで直ちに `unsupported` としない。その差が結論に影響する経路と、橋渡し根拠の有無を示す。

## 推論の格上げ

| 推論タイプ | 検出する変化 | 不足しやすい根拠 |
|---|---|---|
| 相関から因果 | 関連する、予測する → 引き起こす | 無作為化、自然実験、時間順序、交絡統制、因果機序 |
| 示唆から証明 | 可能性、一貫する → 証明した、確定した | 独立再現、競合仮説の排除、頑健性 |
| 事例から一般則 | 一事例、一標本 → 常に、一般に | 比較標本、代表性、再現性 |
| 群間差から本質 | 観測された平均差 → 生得的、固定的 | 代替説明、群内分散、可塑性、測定不変性 |
| 集団から個人 | 集団傾向 → 個人の判定 | 個人予測性能、偽陽性・偽陰性、基準率 |
| 記述から規範 | 事実である → そうすべき | 価値前提、権利、便益と害、代替案、分配影響 |
| 代理指標から実体 | 尺度や代理変数 → 対象概念そのもの | 構成概念妥当性、測定誤差、別指標との整合性 |

経験的前提が `supported` でも、規範的結論は別命題として判定する。研究結果だけから価値前提を導かない。

## 橋渡し根拠の評価

橋渡し根拠について次を確認する。

- 移送元と移送先を直接比較しているか。
- 原研究と同じ構成概念や評価項目を測っているか。
- 結果が独立した研究者や別環境で再現されているか。
- 支持研究だけでなく反証研究や境界条件があるか。
- 理論が移送可能性を説明するだけでなく、反証可能な予測を持つか。
- レビュー論文の検索範囲、選定基準、異質性、出版バイアスを確認できるか。

対象を絞った検索で資料が見つからない場合は「確認できない」と書く。網羅的な不存在主張には、事前に定めた検索式、複数データベース、選定基準を持つ体系的レビューが必要である。

## integrity_concern

次の2条件を両方満たす場合だけ `true` とする。

1. 選択的引用、重大な限界の脱落、属性の本質化、撤回情報の無視など、具体的な問題を資料上で確認できる。
2. その問題が政策、医療、教育、雇用、報道などで深刻な誤導、偏見、排除、不利益な意思決定へつながる現実的な経路を説明できる。

`true` の場合も、問題のある表現と害の経路を示すにとどめる。故意、欺瞞、差別意図、研究不正を断定しない。

次だけでは `true` にしない。

- `unsupported` である。
- 題材が政治的または社会的に論争的である。
- 標本が小さい、または限界がある。
- 援用者と見解が異なる。

## 修正文

修正文では次を守る。

- 対象、条件、時点、研究デザインを必要な範囲で残す。
- 「示唆する」「関連した」など、原研究の確実性を保つ。
- 効果の方向だけでなく、判断に必要なら大きさと不確実性を残す。
- 原研究が扱っていない移送先や価値判断を加えない。
- 修正しても支えられない命題は、もっともらしい限定語で救済せず削除を提案する。
