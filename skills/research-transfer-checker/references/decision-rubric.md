# 判定ルーブリック

## 判定軸

主判定は独立した2軸に分ける。1つの命題は、引用としての忠実性（`citation_support`）と、射程移送の妥当性（`transfer_status`）を別々に判定される。

### citation_support（原研究自身への忠実性）

命題が、原研究自身の対象・方法・結論・確実性を正しく反映しているかを判定する。射程移送（対象を別の種・集団・文化・時代・制度・概念へ広げること）はこの軸では評価しない。

| 値 | 条件 |
|---|---|
| `direct` | 命題が原研究の結論・対象・確実性をそのまま正確に反映しており、限定語を補う必要がない |
| `qualified` | 中核の方向性は原研究と整合するが、対象範囲、条件、効果の大きさ、不確実性、代替説明のいずれかを明示しないと誤解を招く |
| `overextended` | 原研究の確実性・対象・結論を超えて格上げされている（相関→因果、示唆→証明、事例→一般則など）。限定語を補うだけでは救済できず、新しい根拠が要る |
| `contradicted` | 命題が原研究の結論、限界、または訂正・懸念表明・撤回情報と明確に矛盾する |
| `unverifiable` | 上記いずれかを判定するために必要な資料の箇所を確認できず、矛盾を示す明白な手がかりもない |

`qualified` と `overextended` の境界は、限定語だけで原研究に沿うかで決める。限定語を補えば原研究が直接支える命題になる場合は `qualified`、因果識別や新しい比較研究など別の根拠が要る場合は `overextended` とする。

### transfer_status（射程移送の妥当性）

命題が原研究自身の対象・文脈を超えて別の対象へ適用されているか、されている場合にその移送が橋渡し根拠で支えられているかを判定する。

| 値 | 条件 |
|---|---|
| `no_transfer` | 命題が原研究の対象・文脈のままで、種・集団・個人・文化・時代・制度・概念のいずれの軸でも移送を伴わない |
| `justified` | 射程移送があり、検証済みの十分な橋渡し根拠（比較研究、再現研究、理論など）が移送先への適用を支持している |
| `plausible_but_uncertain` | 移送はもっともらしいが、橋渡し根拠が部分的、未確認、または支持と境界条件の両方に読める |
| `not_established` | 対象を絞った探索でも移送を支持する橋渡し根拠を確認できない、または反証研究・境界条件を示す資料が見つかっている |
| `not_assessed` | 移送の有無や橋渡し根拠を評価するために必要な資料を確認できない |

### source_access（資料の取得状況）

命題の判定に使った資料それぞれについて、次のいずれかを付ける。複数資料を使う命題では、判定へ直接使った資料の中で最も弱いものを基準にする。

| 値 | 条件 |
|---|---|
| `full_verified` | 全文を確認でき、資料の同一性（著者・題名・年・掲載元・DOI等）と、訂正・懸念表明・撤回・査読版更新の有無も確認できた |
| `full_unverified` | 全文は確認できたが、同一性、または訂正・撤回情報のいずれかを確認できていない |
| `abstract_only` | 抄録・構造化抄録のみ確認できた。全文は確認できていない |
| `secondary_only` | レビュー、記事などの二次資料の記述からのみ確認できた。原論文自体は未確認 |
| `unavailable` | 資料そのものにアクセスできない |

## 非対称ゲート

肯定的判定（`citation_support` の `direct` / `qualified`、`transfer_status` の `justified`）は、原則として全文検証を要件とする。`source_access` が `full_verified` に満たない資料からは、これらの値を付けない。`full_unverified` も対象や同一性の確認が不十分なため、肯定的判定の根拠にしない。

否定的判定（`citation_support: overextended` / `contradicted`、`transfer_status: not_established`）は、資料の記述が主張と明確に矛盾する、または格上げが明確に読み取れる場合、全文がなくても付けてよい。例えば抄録が相関研究であることを明示しているのに主張が因果を述べている場合、全文がなくても `overextended` である。

`plausible_but_uncertain` は `transfer_status` の非対称ゲートの対象外であり、判定の根拠が実際に確認できた資料の範囲内にあれば、`full_verified` に満たない `source_access` からでも付けてよい。確認できていない範囲に判定根拠が及ぶ場合は、その部分を `not_assessed` とする。

全文の一部だけを確認できない場合は、確認できない部分だけを `unverifiable` / `not_assessed` とする。他の軸や他の命題は、確認できた資料の範囲で通常どおり判定する。ケース全体を検証不能として扱わない。

## 原研究との整合性（citation_support の判断材料）

次の差が援用主張の結論を変えるかを確認する。

- 著者の結論より強い確実性を使っていないか。
- 主要評価項目と副次評価項目を入れ替えていないか。
- 統計的有意性を効果の大きさや実用上の重要性と同一視していないか。
- 相対効果だけを示し、絶対効果や基準率を隠していないか。
- 探索的解析や事後解析を事前仮説の検証として扱っていないか。
- 否定的結果を「効果がない証明」として扱っていないか。
- 除外基準、脱落、欠測、測定誤差、交絡、バイアスを落としていないか。

## 射程移送の軸（transfer_status の判断材料）

| 軸 | 典型的な飛躍 | 必要になり得る橋渡し根拠 |
|---|---|---|
| 種 | 動物や細胞から人間 | 機序の比較、薬物動態、臨床研究、トランスレーショナル研究 |
| 集団 | 限定標本から別集団 | 代表性、再現研究、効果修飾、外的妥当性の分析 |
| 集団から個人 | 平均差から個人の能力や性質 | 個人レベルの予測妥当性、誤分類率、基準率 |
| 文化・地域 | 一地域から普遍的傾向 | 測定不変性、文化間比較、制度差の分析 |
| 時代 | 過去の結果から現在 | 環境変化、コホート効果、再現研究 |
| 制度 | 実験環境から政策・組織運用 | 実装研究、制度比較、副作用、分配影響 |
| 概念 | 測定指標から広い概念 | 構成概念妥当性、収束的・弁別的妥当性 |

差があるだけで直ちに `not_established` としない。その差が結論に影響する経路と、橋渡し根拠の有無を示す。

## reasoning_type（推論の格上げの分類）

`citation_support` を `overextended` にする典型的な推論の格上げを分類する。該当する型がなければ「該当なし」とする。射程移送が主要因の場合は、上表の軸名（種、集団、集団から個人など）を使ってよい。

| 推論タイプ | 検出する変化 | 不足しやすい根拠 |
|---|---|---|
| 相関から因果 | 関連する、予測する → 引き起こす | 無作為化、自然実験、時間順序、交絡統制、因果機序 |
| 示唆から証明 | 可能性、一貫する → 証明した、確定した | 独立再現、競合仮説の排除、頑健性 |
| 事例から一般則 | 一事例、一標本 → 常に、一般に | 比較標本、代表性、再現性 |
| 群間差から本質 | 観測された平均差 → 生得的、固定的 | 代替説明、群内分散、可塑性、測定不変性 |
| 記述から規範 | 事実である → そうすべき | 価値前提、権利、便益と害、代替案、分配影響 |
| 代理指標から実体 | 尺度や代理変数 → 対象概念そのもの | 構成概念妥当性、測定誤差、別指標との整合性 |

経験的前提の `citation_support` が `direct` でも、規範的結論は別命題として判定する。研究結果だけから価値前提を導かない。

## 橋渡し根拠の評価（transfer_status の判断材料）

橋渡し根拠について次を確認する。

- 移送元と移送先を直接比較しているか。
- 原研究と同じ構成概念や評価項目を測っているか。
- 結果が独立した研究者や別環境で再現されているか。
- 支持研究だけでなく反証研究や境界条件があるか。
- 理論が移送可能性を説明するだけでなく、反証可能な予測を持つか。
- レビュー論文の検索範囲、選定基準、異質性、出版バイアスを確認できるか。

対象を絞った検索で資料が見つからない場合は「確認できない」と書く。網羅的な不存在主張には、事前に定めた検索式、複数データベース、選定基準を持つ体系的レビューが必要である。

## confidence

命題ごとの `confidence` は「高」「中」「低」の3段階で付ける。

- 高: 橋渡し根拠または引用箇所が直接的で、`source_access` が十分であり、複数の判断材料が一致する。
- 中: 判断材料の一部が間接的、部分的、または未確認である。
- 低: 判断材料の大部分が間接的、推測を要する、または資料の確認範囲が限られる。

## missing_evidence

判定を確定するために不足している資料や、確認できなかった部分を具体的に書く。該当なければ「該当なし」とする。命題の一部だけが `unverifiable` / `not_assessed` の場合は、その部分だけを指す。

## integrity_concern

`integrity_concern` は `citation_support` と `transfer_status` のいずれからも独立した警告として、`true` または `false` を付ける。次の2条件を両方満たす場合だけ `true` とする。

1. 選択的引用、重大な限界の脱落、属性の本質化、撤回情報の無視など、具体的な問題を資料上で確認できる。
2. その問題が政策、医療、教育、雇用、報道などで深刻な誤導、偏見、排除、不利益な意思決定へつながる現実的な経路を説明できる。

`true` の場合も、問題のある表現と害の経路を示すにとどめる。故意、欺瞞、差別意図、研究不正を断定しない。

次だけでは `true` にしない。

- `citation_support` が `overextended` または `contradicted` である。
- `transfer_status` が `not_established` である。
- 題材が政治的または社会的に論争的である。
- 標本が小さい、または限界がある。
- 援用者と見解が異なる。

資料に一切アクセスできない場合（`source_access: unavailable`）は `判定保留` とする。

## corrected_claim

修正文では次を守る。

- 対象、条件、時点、研究デザインを必要な範囲で残す。
- 「示唆する」「関連した」など、原研究の確実性を保つ。
- 効果の方向だけでなく、判断に必要なら大きさと不確実性を残す。
- 原研究が扱っていない移送先や価値判断を加えない。
- 修正しても支えられない命題は、もっともらしい限定語で救済せず削除を提案する。
