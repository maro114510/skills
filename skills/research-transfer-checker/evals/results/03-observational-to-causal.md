# Case 03 結果: 観察研究から因果主張への格上げ / observational-to-causal claim

ケース定義: `../03-observational-to-causal.md`

## Baseline（no-skill）transcript

この主張は受け入れられません。修正を求めます。

「3杯以上飲めば予防できる」という言い方は、緑茶摂取という行動を取ればストローク予防という結果が得られる、という介入的・因果的な言い回しです。しかし元論文は前向きコホート研究であり、無作為割付を伴わない観察研究です。ハザード比0.80（95%CI 0.70-0.92）という結果自体は交絡因子調整済みで、関連としては悪くない数字ですが、著者自身が限界の項で「時間順序は満たすが、緑茶を多く飲む人は運動や食生活、社会経済的要因など他の面でも健康的である可能性があり、これらを統計調整だけでは排除しきれない」「因果関係を確定することはできない」と明言し、結論でも「関連が観察された」「因果関係の確認には介入研究が必要」とわざわざ書いています。つまり著者自身が一番慎重にしているポイントを、この主張は無視して因果・実践指示（〜すれば防げる）にすり替えてしまっています。

典型的な「相関を因果として語ってしまう」パターンで、しかも元論文がご丁寧に「これは因果ではない」と自己申告しているケースなので、判断に迷う余地はほとんどありません。修正するなら「緑茶を1日3杯以上飲む人では、ほとんど飲まない人に比べて脳卒中発症率が低いという関連が観察されている（ただし観察研究であり因果関係は未確定）」くらいの書き方が妥当です。

確信度は高いです。

## With-skill transcript（standard モード）

```markdown
## Research Transfer Check

### 対象
- モード: standard
- 援用したい主張: 「毎日緑茶を3杯以上飲めば、脳卒中の発症を予防できる」
- 参照元: Morita K, Fujikawa S. (2020)

### 判定サマリー
- citation_support: overextended 1件
- transfer_status: plausible_but_uncertain 1件
- integrity_concern: true
- 最も重大な問題: 前向きコホート研究（観察研究・無作為割付なし）で得られた統計的関連（ハザード比0.80）を、著者自身が明記した「因果関係の確認には介入研究が必要」という限定を落として、確定的な予防効果（因果）として提示している。

#### C1
- citation_support: overextended
- transfer_status: plausible_but_uncertain
- source_access: full_verified
- confidence: 中
- integrity_concern: true
- reasoning_type: 相関から因果（主）。加えて、集団（研究対象集団＝40〜79歳で脳卒中・心疾患の既往のない地域住民18,500名から、年齢・既往歴を問わない一般公開読者全体への暗黙の拡大）
- 問題のある推論箇所: 「飲めば…予防できる」という文言。原論文は観察研究であり、著者は「時間順序のみをもって因果関係を確定することはできない」と明記している。
```

## 採点

**期待される判定**: citation_support `overextended` / transfer_status `no_transfer` / reasoning_type `相関から因果` / integrity_concern `false`。

**採点基準チェック**:
- [x] citation_support は `overextended` — 正解（因果格上げを正しく検出）
- [x] reasoning_type に「相関から因果」を含む — 正解
- [ ] transfer_status が `no_transfer` 以外に判定された場合は不正解 → **不正解**（`plausible_but_uncertain`）
- [x] 因果を断定する文言を出力自身は含んでいない — 正解
- [ ] integrity_concern は期待値 `false` → **不一致**（`true`。理由は著者の限界記述の省略という「根拠不足」の域を出ず、選択的引用や重大な限界脱落という具体的問題を特定できていないため、`true`を許容する条件を満たさない）

**判定: FAIL（部分的）**

中心的な検出対象である「相関→因果」の格上げは baseline・with-skill ともに正しく捉えた。しかしスキルは、対象集団（研究対象の40〜79歳・既往なし地域住民）と「一般公開の読者全体（年齢・既往歴を問わない）」との違いを独自に射程移送の問題として持ち込み、`transfer_status` を `no_transfer` から `plausible_but_uncertain` へ引き下げた。本ケースは対象集団に変更がないことを前提に設計されており、この追加の移送軸はスキル側の解釈拡張によるもので、Case 01・05・08 と同種の「意図されていない曖昧さの創出」パターンである。

integrity_concern も期待値は `false`（許容される揺れとしては、具体的な害の経路説明を伴う場合に限り `true` も許容）だが、agent の理由付けは著者の限界記述の省略という「根拠不足」の枠に留まり、選択的引用等の具体的問題を特定できていないため、許容条件を厳密には満たしていない。
