# lessons-summary.md 出力フォーマット仕様

このファイルを Read して、統合ファイル生成時のフォーマット基準として使う。

---

## 統合ルール

1. **重複排除**: 同じ趣旨の指摘が複数バッチに存在する場合は1つにまとめ、`（複数PRで指摘: N回）` と注記する
2. **頻度順**: 同じ観点の中では、指摘回数の多い教訓を上位に配置する
3. **出典を保持**: 各教訓に「初出 PR: #xxx」を残す
4. **空の観点は省略**: 教訓が一件もない観点は見出しごと省略する

## 見出しレベル変換

バッチファイル（`/tmp/pr-lessons/batch-*.md`）の見出しレベルを以下のとおり昇格する：

| バッチ | 統合ファイル |
|---|---|
| `### 技術的な指摘`（H3） | `## 1. 技術的な指摘（コード品質・設計）`（H2） |
| `#### [教訓タイトル]`（H4） | `### [教訓タイトル]`（H3） |
